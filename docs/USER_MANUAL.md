# SCIEHub 用户手册

SCIEHub 是面向国际高中生的**学习资源共享/售卖市场**。你可以免费分享自己的资料，也可以标价售卖；既可以免费下载他人的共享，也可以购买付费资源。

> 界面为英文。本文是各功能的中文使用说明。

## 1. 账号

- **注册/登录**：点击右上角 **Sign in**，进入 `/auth` 页签切换注册或登录。使用邮箱 + 密码。
- **首个注册用户**：全新部署下，第一个注册成功的账号会自动成为网站管理员。
- **个人资料**：登录后在头像菜单 → **Profile** 可查看你的主页；**Settings** 可修改昵称、简介、头像颜色、密码，并查看登录历史、登出所有设备、停用/删除账号。

## 2. 浏览与搜索资源

- 顶部导航 **Marketplace**（或首页 **Browse marketplace**）进入资源市场 `/marketplace`。
- 支持：
  - **关键词搜索**：顶部搜索框输入关键词（标题、描述、标签）。
  - **分类筛选**：Mathematics / Physics / Chemistry / Computer Science 等。
  - **定价筛选**：All pricing / Free only / Paid only。
  - **排序**：Most recent（最新）、Most downloaded（下载最多）、Most viewed（浏览最多）、Most sold（销量最高）、Top rated（评分最高）、Price: low→high / high→low（价格）。
- 资源卡片会显示**价格或 "Free" 徽章**、销量、评分等信息。

## 3. 下载免费资源

- 打开一个标记为 **Free** 的资源，直接点击文件旁的下载图标即可，无需付费、无需登录也可预览。
- 每个文件都有独立的下载次数统计。

## 4. 发布资源(免费或标价)

1. 点击右上角 **Upload & Sell** 进入 `/upload`。
2. 填写仓库信息：名称、描述、分类、标签；可分享到自己的小组。
3. **定价**：
   - 选 **Free download**：所有人免费下载。
   - 选 **Paid resource**：输入价格（0.01 – 9,999）与币种（¥ CNY / $ USD）。
4. 拖拽或选择文件（可多个），逐个显示上传进度。
5. 上传成功后进入资源详情页。

> 之后可以随时在资源详情页点 **Edit** 修改名称、描述、分类、标签、**定价**和预览图 URL。

### 平台费用

平台从每笔销售中抽取 **10% 平台费**，其余 **90%** 归卖家（进入卖家钱包）。费用在结账页（Checkout）和资源详情页都会清晰展示。

## 5. 购买付费资源

1. 打开一个标记价格（非 Free、非你自己、尚未购买）的资源。
2. 在右侧 **价格面板** 点击 **Buy now** 进入 `/checkout/:id`。
3. 核对 **Order summary**（商品价格 / 平台费 / 卖家所得 / 应付总额）。
4. 确认钱包余额充足后点击 **Pay ¥…**，从钱包即时扣款。
5. 支付成功后页面提示 **Purchase complete**，该资源的全部文件解锁，可直接下载。

> 未登录时无法购买；请先登录。支付成功后资源会出现在你个人主页的 **Purchases**（已购）页签里。

## 6. 钱包与余额

- 顶部导航显示你的钱包余额（¥）。点击进入 `/wallet`。
- 钱包页面展示：
  - **可用余额**；
  - **总收入 / 总支出 / 待结算** 统计；
  - **交易流水**：按类型筛选（Purchases / Sales / Refunds / Top-ups / Withdrawals），每条含金额与余额变动。
- **收入来源**：每笔成功的销售，扣除平台费后自动进入你的钱包（记录为 `Sale`）。
- **充值/提现**：由平台管理员操作。管理员在 `/admin` → Users 可对任意用户充值钱包（`Top up`）。
  - 若余额不足无法支付，请联系管理员充值。

## 7. 我的订单

- 点击顶部 **Orders** 进入 `/orders`，分两个视角（页签切换）：
  - **As buyer（我买的）**：可对 **Pending**（待支付）订单点 **Pay now** 用钱包支付；支付后解锁资源。
  - **As seller（我卖的）**：查看每笔销售的收入；对 **Paid** 订单可点 **Refund** 退款。
- 支持按状态筛选（All / Pending / Paid / Refunded / Cancelled）。

### 退款规则

- **卖家发起**：卖家对已支付订单点 Refund 后，买家的付款退回买家钱包、卖家的收入被扣回，买家的下载权限移除。
- **管理员发起**：管理员在 `/admin` → Orders 可对任意已支付订单退款。
- 买家如需退款，请联系卖家或管理员。

## 8. 评价与评分

- **谁能评价**：已购买该资源的用户（免费资源的创建者也可评价自己的资源）。
- **如何评价**：在资源详情页的评价区选择 **1–5 星**，可加标题和正文，点 **Submit review**。
- **管理评价**：自己的评价可 **Edit** 或 **Delete**。
- 每个资源的**平均分**显示在评价区标题和资源卡片上。

## 9. 学习小组

- 浏览 `/groups` 查看所有小组并可创建新小组。
- 加入小组需点击 **Join** 提交申请，由小组创建者（管理员）审批。
- 小组创建者可将自己的资源**分享**进小组（在资源详情页操作）。
- 小组创建者可管理成员、审批加入申请、删除小组。

## 10. 常见问题

| 问题 | 回答 |
| --- | --- |
| 余额不足怎么购买？ | 联系管理员充值钱包（`/admin` → Users → Top up）。 |
| 买错了/内容与描述不符？ | 联系卖家退款，或联系管理员处理。 |
| 我的收入到哪里了？ | 每笔销售扣除 10% 平台费后自动进入你的钱包（`/wallet`）。 |
| 免费资源需要登录吗？ | 免费下载不需要登录；评价、收藏、评论需要登录。 |
| 如何修改资源价格？ | 打开资源详情 → **Edit** → 修改 Pricing 后保存。 |
| 上传文件有限制吗？ | 单个文件最大 50 MB，支持 PDF/Word/PPT/图片/代码/音视频/压缩包。 |
| 忘记密码？ | 登录页点 "Contact the admin to reset it"，用你的邮箱联系 `jasonsun2009@yeah.net`。 |
| 遇到问题/想反馈？ | 到 `/contributing` 发邮件反馈，或到 GitHub 仓库提 issue。 |
