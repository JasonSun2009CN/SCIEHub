# SCIEHub 用户手册

SCIEHub 是面向国际高中生的**免费学习资料库 + 社区**。所有笔记、练习题和 past paper 都可以免费下载；你也可以用用户名或匿名发布自己的资料。

> 界面为英文。本文是各功能的中文使用说明。

## 1. 账号

- **注册/登录**：点击右上角 **Sign in**，进入 `/auth` 页签切换注册或登录。
- **只允许学校邮箱**：格式为 `s12345.chen@stu.scie.com.cn`，即 `s` + 学号 + `.` + 姓氏 + `@stu.scie.com.cn`。校外邮箱会被拒绝，用于防止外校人员访问。
- **首个注册用户**：全新部署下，第一个注册成功的账号会自动成为网站管理员。
- **个人资料**：登录后在头像菜单 → **Profile** 可查看你的主页；**Settings** 可修改昵称、简介、头像颜色、密码，并查看登录历史、登出所有设备、停用/删除账号。

## 2. 浏览与搜索资源

- 顶部导航 **Library** 进入 `/library`，这是网站唯一的资料库。
- 支持：
  - **关键词搜索**：顶部搜索框输入关键词（标题、描述、标签）。
  - **Level 筛选**：IGCSE / IG、AS、A Level、IB、AP、Other。
  - **Subject 筛选**：Mathematics、Further Mathematics、Physics、Chemistry、Biology、English Literature、English Language、Chinese、Computer Science、History、Geography、Economics、Business、Psychology 等。
  - **Resource type 筛选**：Notes（笔记）、Practice Questions（练习题）、Past Papers（past paper）、Other。
  - **排序**：Newest（最新）、Most downloaded（下载最多）、Most viewed（浏览最多）、Top rated（评分最高）。
- 资源卡片会显示 **Free** 徽章、Level、资源类型、评分等信息。

## 3. 在线预览与下载

- 打开资源详情页，在文件列表中点击 **眼睛图标** 即可在浏览器内预览，无需下载。
- 点击 **下载图标** 直接下载原文件，无需付费、无需登录。
- 每个文件都有独立的下载次数统计。

## 4. 发布资源

1. 点击右上角 **Publish** 进入 `/upload`。
2. 填写仓库信息：名称、描述、**Level**（IG / AS / A Level / IB / AP）、**Subject**（学科）、**Resource type**（Notes / Practice Questions / Past Papers）、标签；可分享到自己的小组。
   - **Tags**：输入一个 tag 后按 **Enter**（或逗号）生成一个标签；例如输入 `Litcharts` 回车、再输入 `Literature` 回车，就是两个标签。最多 8 个。
3. **Publish anonymously**：开启后隐藏你的用户名；所有资源都可以匿名发布。
4. 拖拽或选择文件（可多个），逐个显示上传进度。
5. 上传成功后进入资源详情页。

> 之后可以随时在资源详情页点 **Edit** 修改名称、描述、Level、Subject、Resource type、标签、匿名状态和预览图 URL。
>
> **文件传错了**：资源详情页 → Files 列表 → 文件右侧的删除按钮；删除后在资源详情页点 **Upload files** 重新上传正确文件。删除会同时移除 R2 中的文件，无法恢复。

## 5. 在线预览支持的格式

- **PDF**：在弹窗中直接使用浏览器 PDF 阅读器查看，可滚动、缩放和打印。
- **图片**：PNG / JPG / JPEG / WebP / GIF / AVIF 会直接显示在弹窗中。
- **其他格式**（Word、PPT、压缩包、音视频等）：请下载后使用本地软件打开。

## 6. The Commons 与 Plaza

### The Commons

- 顶部导航 **Community** 进入 `/community`。
- 所有登录用户都可以发帖：问题、学习技巧、资料请求、学习进展等。
- 发帖时可选择 **Post as @username** 或 **Posting anonymously**。
- 帖子每 10 秒自动刷新；自己的帖子可删除，管理员可删除任何帖子。
- 管理员可以单独关闭某个账号的社区发帖权限。

### Plaza（校园墙）

- 顶部导航 **Plaza** 进入 `/plaza`。
- 类似 X 的校园墙：文字 + 图片帖子，支持点赞和评论。
- 每条帖子最多 **4 张图片**，单张最大 **10MB**；支持 JPG / PNG / WebP / GIF / AVIF。
- **暂不支持视频**，上传视频会被拒绝。
- 可以用户名发布或匿名发布；评论也可以匿名。
- 自己的帖子/评论可删除，管理员可删除任何内容。
- 图片会存入 R2；删除帖子时图片一并删除。

## 7. 评价与评分

- **谁能评价**：任何登录用户都可以评价。
- **如何评价**：在资源详情页的评价区选择 **1–5 星**，可加标题和正文，点 **Submit review**。
- **管理评价**：自己的评价可 **Edit** 或 **Delete**。
- 每个资源的**平均分**显示在评价区标题和资源卡片上。

## 8. 学习小组

- 浏览 `/groups` 查看所有小组并可创建新小组。
- 加入小组需点击 **Join** 提交申请，由小组创建者（管理员）审批。
- 小组创建者可将自己的资源**分享**进小组（在资源详情页操作）。
- 小组创建者可管理成员、审批加入申请、删除小组。

## 9. 版权与内容下架

- **只上传自己的作品**，或你明确拥有分享权限的资料。
- 不要重新上传商业 past paper、付费内容或他人的笔记。
- **如果你的笔记被别人未经允许上传到这里**：请联系管理员（`jasonsun2009@yeah.net`），附上资源链接，管理员会删除相关内容。
- 收到有效下架请求后，管理员可以直接删除资源、文件或帖子。

## 10. 常见问题

| 问题 | 回答 |
| --- | --- |
| 下载需要付费吗？ | 不需要。SCIEHub 上的所有资源都免费下载。 |
| 需要登录才能下载吗？ | 不需要；评价、收藏、评论、发帖需要登录。 |
| 如何匿名发布？ | 在 `/upload` 开启 **Publish anonymously**。 |
| 为什么不能发帖/发布？ | 管理员可能关闭了某项权限；请联系管理员。 |
| 可以预览 PDF 吗？ | 可以，在资源详情页点击 PDF 文件旁的眼睛图标即可在线预览。 |
| 我的笔记被他人上传了怎么办？ | 联系管理员并提供资源链接，管理员会删除。 |
| 上传文件有限制吗？ | 单个文件最大 50 MB，支持 PDF/Word/PPT/图片/代码/音视频/压缩包。 |
| 忘记密码？ | 登录页点 "Contact the admin to reset it"，用你的邮箱联系 `jasonsun2009@yeah.net`。 |
| 遇到问题/想反馈？ | 到 `/contributing` 发邮件反馈，或到 GitHub 仓库提 issue。 |
