# SCIEHub 用户手册

SCIEHub 是面向国际高中生的**免费优先学习资料库 + 社区**。你可以免费分享或下载笔记、练习题和 past paper；也可以选择标价发布，让感兴趣的买家通过邮箱联系你，在其他平台完成交易。

> 界面为英文。本文是各功能的中文使用说明。

## 1. 账号

- **注册/登录**：点击右上角 **Sign in**，进入 `/auth` 页签切换注册或登录。
- **只允许学校邮箱**：格式为 `s24427.sun@stu.scie.com.cn`，即 `s` + 学号 + `.` + 姓氏 + `@stu.scie.com.cn`。校外邮箱会被拒绝，用于防止外校人员访问。
- **首个注册用户**：全新部署下，第一个注册成功的账号会自动成为网站管理员。
- **个人资料**：登录后在头像菜单 → **Profile** 可查看你的主页；**Settings** 可修改昵称、简介、头像颜色、密码，并查看登录历史、登出所有设备、停用/删除账号。

## 2. 浏览与搜索资源

- 顶部导航 **Marketplace** 进入全部资源；**Free** 进入免费专区 `/free`；**Paid** 进入付费专区 `/paid`。
- 支持：
  - **关键词搜索**：顶部搜索框输入关键词（标题、描述、标签）。
  - **Level 筛选**：IGCSE / IG、AS、A Level、IB、AP、Other。
  - **Subject 筛选**：Mathematics、Further Mathematics、Physics、Chemistry、Biology、English Literature / Language、Chinese、Computer Science、History、Geography、Economics、Business、Psychology 等。
  - **Resource type 筛选**：Notes（笔记）、Practice Questions（练习题）、Past Papers（past paper）、Other。
  - **定价筛选**（全部资源页）：All pricing / Free only / Paid only。
  - **排序**：Most recent（最新）、Most downloaded（下载最多）、Most viewed（浏览最多）、Most sold（销量最高）、Top rated（评分最高）、Price: low→high / high→low（价格）。
- 资源卡片会显示**价格或 "Free" 徽章**、Level、资源类型、销量、评分等信息。

## 3. 下载免费资源

- 打开一个标记为 **Free** 的资源，直接点击文件旁的下载图标即可，无需付费、无需登录也可预览。
- 每个文件都有独立的下载次数统计。

## 4. 发布资源（免费优先）

1. 点击右上角 **Publish** 进入 `/upload`。
2. 填写仓库信息：名称、描述、**Level**（IG / AS / A Level / IB / AP）、**Subject**（学科）、**Resource type**（Notes / Practice Questions / Past Papers）、标签；可分享到自己的小组。
   - **Tags**：输入一个 tag 后按 **Enter**（或逗号）生成一个标签；例如输入 `Litcharts` 回车、再输入 `Literature` 回车，就是两个标签。最多 8 个。
3. **Pricing**：
   - 选 **Free**：所有人免费下载（推荐）。
   - 选 **Paid**：输入价格（0.01 – 9,999）与币种。付费资源不会在站内扣款，买家会向你发送联系请求。
4. **Publish anonymously**：免费资源可开启匿名发布，隐藏你的用户名；付费资源必须使用用户名发布。
5. 拖拽或选择文件（可多个），逐个显示上传进度。
6. 上传成功后进入资源详情页。

> 之后可以随时在资源详情页点 **Edit** 修改名称、描述、Level、Subject、Resource type、标签、匿名状态、定价和预览图 URL。

## 5. 付费资源：联系卖家，站外交易

SCIEHub **不处理付费资源的支付**。付费资源是一种“联系卖家”的入口：

1. 打开一个付费资源，点击 **Request purchase**。
2. 填写可选留言，发送请求。
3. 卖家会在 **Purchase requests** 中看到你的**账号邮箱**、用户名、资源名称和留言。
4. 卖家通过邮箱联系你；你们自行选择其他平台完成付款和文件交付。
5. 卖家可将请求标记为 **Contacted / Completed / Declined**；你也可以在 **Sent** 页签取消请求。

> 买家不会看到卖家的邮箱；卖家先拿到买家邮箱并主动联系。请只在可信渠道完成交易，平台不承担站外交易风险。

## 6. Purchase requests（购买请求）

- 点击头像菜单 → **Purchase requests** 进入 `/requests`。
- **Incoming**：你作为卖家收到的请求，显示买家邮箱（可直接 mailto）、资源、留言和状态。
- **Sent**：你作为买家发出的请求，显示卖家、资源、留言和状态。
- 新请求每 15 秒自动刷新；卖家可标记 Contacted / Completed / Declined，买家可取消。

## 7. The Commons（社区）

- 顶部导航 **Community** 进入 `/community`。
- 所有登录用户都可以发帖：问题、学习技巧、资料请求、学习进展等。
- 发帖时可选择 **Post as @username** 或 **Posting anonymously**。
- 帖子每 10 秒自动刷新；自己的帖子可删除，管理员可删除任何帖子。
- 管理员可以单独关闭某个账号的社区发帖权限。

## 8. 评价与评分

- **谁能评价**：免费资源的创建者；付费资源需卖家将你的购买请求标记为 **Completed** 后才能评价。
- **如何评价**：在资源详情页的评价区选择 **1–5 星**，可加标题和正文，点 **Submit review**。
- **管理评价**：自己的评价可 **Edit** 或 **Delete**。
- 每个资源的**平均分**显示在评价区标题和资源卡片上。

## 9. 学习小组

- 浏览 `/groups` 查看所有小组并可创建新小组。
- 加入小组需点击 **Join** 提交申请，由小组创建者（管理员）审批。
- 小组创建者可将自己的资源**分享**进小组（在资源详情页操作）。
- 小组创建者可管理成员、审批加入申请、删除小组。

## 10. 常见问题

| 问题 | 回答 |
| --- | --- |
| 怎么购买付费资源？ | 点 **Request purchase**，卖家会收到你的邮箱并联系你；付款在站外完成。 |
| 买错了/内容与描述不符？ | 直接联系卖家协商；站外交易风险由双方承担，也可联系管理员处理违规内容。 |
| 平台收手续费吗？ | 目前不处理站内支付，因此不收取交易手续费。 |
| 免费资源需要登录吗？ | 免费下载不需要登录；评价、收藏、评论、发帖需要登录。 |
| 如何匿名发布？ | 在 `/upload` 选择 **Free**，开启 **Publish anonymously**。付费资源必须使用用户名。 |
| 为什么不能发帖/发布/购买？ | 管理员可能关闭了某项权限；请联系管理员。 |
| 上传文件有限制吗？ | 单个文件最大 50 MB，支持 PDF/Word/PPT/图片/代码/音视频/压缩包。 |
| 忘记密码？ | 登录页点 "Contact the admin to reset it"，用你的邮箱联系 `jasonsun2009@yeah.net`。 |
| 遇到问题/想反馈？ | 到 `/contributing` 发邮件反馈，或到 GitHub 仓库提 issue。 |
